# Project Summary

Kaarox est une plateforme de présence professionnelle et de découverte commerciale. Elle permet aux particuliers, professionnels et entreprises de créer une carte de visite numérique, de présenter leurs services, d’être trouvés par secteur et localisation, puis d’échanger avec leur audience via la messagerie, les réservations, les communautés, la marketplace et le partage prolongé.

La landing page propose désormais une expérience narrative cinématique au scroll, avec une composition de panneaux d’interface Kaarox à la place du mockup de téléphone. Le hero présente la recherche, la carte professionnelle, les réservations, la messagerie, la marketplace et Prolonged Share au-dessus d’une vidéo verticale. Les chapitres clients, prestataires, communautés, industries et technologie utilisent onze clips vidéo distincts, dont quatre nouveaux pour le plein air, les services locaux, le garage et la moto.

# Project Module Description

- **Landing page** : présentation de Kaarox, proposition de valeur, hero, chapitres narratifs et CTA.
- **Hero produit** : composition responsive de panneaux UI flottants avec parallaxe, vidéo verticale et animations d’entrée.
- **Panneaux UI** : représentations de la recherche, carte professionnelle, réservation, messagerie, marketplace et Prolonged Share.
- **Séquence d’introduction** : animation de marque jouée une fois par session et désactivée avec `prefers-reduced-motion`.
- **Real Life** : section en deux colonnes présentant Beauty, Sport et Wellness sans chevauchement entre texte et médias.
- **Parcours clients** : découverte, exploration, connexion, réservation et maintien de la relation avec vidéos, écrans applicatifs et panneaux UI.
- **Parcours prestataires** : présentation de l’identité professionnelle, des services, de la visibilité, des demandes et du partage.
- **Prolonged Share** : animation sticky pilotée par le scroll et réversible au défilement inverse.
- **Communauté** : présentation des Posts, Hubs et Messages sur fond vidéo.
- **Industries** : montage de secteurs avec fenêtres vidéo extensibles selon la progression du scroll.
- **Technologie** : chapitre atmosphérique sur la pertinence, la découverte et les personnes.
- **Vidéo web** : clips MP4 sans audio, affiches JPG, chargement différé, lecture du média focalisé et pause hors viewport.
- **Blog** : index, articles Markdown, layouts dédiés et routes pré-rendues.
- **Authentification** : pages de callback et d’erreur.
- **Pages légales** : confidentialité, conditions d’utilisation et remboursement en HTML statique.
- **Composants UI** : bibliothèque réutilisable basée sur Radix/shadcn et Tailwind CSS.
- **Accessibilité et performance** : réduction des animations, lazy loading, Intersection Observer et mises à jour via `requestAnimationFrame`.

# Usage

Depuis le dossier `app/frontend` :

```bash
pnpm install
```

Lancer le serveur de développement :

```bash
pnpm run dev
```

Vérifier le code :

```bash
pnpm run lint
```

Construire la version de production :

```bash
pnpm run build
```

Validation complète :

```bash
pnpm run lint && pnpm run build
```

Les clips et affiches optimisés sont placés dans `public/assets/`. Les pages légales sont copiées dans la sortie de production par Vite. Les contenus du blog sont traités par les scripts du dossier `prerender/`.
